# Tic-Tac-Toe-C-project
Tic-Tac-Toe in C programing language with rule-based AI opponent
A terminal-based Tic-Tac-Toe game with two modes: Two Player and Vs Computer.

## Features
- Rule-based AI opponent (win, block, centre, random)
- Colored board with box-drawing grid
- Score counter and player names
- Menu-driven interface

## How to run
gcc tictactoe_v2.c -o ttt
./ttt

## Built with
C (standard library only)
